# Block instances

Карточка на каждый уникальный блок (label + тело). Дедуп по `(нормализованный label, дословное тело)`.

Тело — все строки от label'а до следующего label / session / day / Quick Search-футера, **без** строки самого label'а. Для `(implicit)`-блоков тело — все строки от 1ST SESSION до первого block-label'а в сессии. Сохранены: пустые-как-в-md строки отбрасываются (md-конвертер их не выводит), пустые «логические» промежутки между schemas внутри блока остаются исключительно как структурные строки типа `- 5 min rest in between sets -` и т.п.

Сортировка карточек: по канону block-labels, внутри label'а — по объёму locations убыванием.
