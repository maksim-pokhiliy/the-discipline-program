## The fix-now set

1. **RF-7 (blocking) — a failed background refetch of the language catalog unmounts the editor and the Pages list in another language and loses the coach's typing.** `apps/admin/src/modules/pages/components/locale-gate/resolve-locale-param.ts:32-38` returns `failed` on `catalog.isError` before it looks at `catalog.data`; in TanStack Query 5.80.2 a failed refetch keeps `data` and sets `isError` (`query-core/build/modern/query.js:337-351`, `queryObserver.js:303,328`), and every non-default save invalidates `adminKeys.locales.list()` (`apps/admin/src/lib/hooks/use-pages.ts:76-79`), the key `useLocales` reads; a window focus past the staleness window is a second trigger. The reviewer reproduced it three times on the real admin tree: the editor replaced by "Failed to load data" about 6.5 s after the save, the typed words gone. Fix: `failed` only when `catalog.data === undefined` and `catalog.isError`; with data cached, the resolution comes from the data whatever `isError` says (the same rule 0.4d1 gave the page itself: `pages-edit-content.tsx:21`, `error={data ? null : error}`). Regression tests: in `resolve-locale-param.test.ts`, `uk` with `{ data: LOCALE_CATALOG, isError: true }` resolves to the catalog entry and an unknown code with the same catalog is `notFound` (the existing `data: undefined, isError: true` case stays `failed`); in `apps/admin/src/modules/pages/views/pages-edit-view/page-locale-lifecycle.test.tsx`, beside its catalog-failure case and with its real query hooks: the Ukrainian editor open on a cached catalog, a word typed into one section, a Ukrainian save of another section whose catalog refetch rejects on every attempt; the editor stays mounted, the typed word is still in its field, and "Failed to load data" never appears. Mutant to show red: the `isError` check moved back before the `data` check.

Regression test in `page-locale-lifecycle.test.tsx`: Ukrainian fresh and translated; switch to English, edit, Update Section with the PATCH held pending; switch back to Ukrainian (no GET on the switch); resolve the PATCH: the Ukrainian section shows "English is newer" with the new English value beside the word, and the English page was fetched exactly once after its save. Mutants to show red: the refetch removed; the predicate removed (English fetched twice).
