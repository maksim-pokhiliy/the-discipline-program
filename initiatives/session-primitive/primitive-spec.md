## 1. The skeleton (D-1..D-4)

```
Session
└─ Block                      секция тренировки (warm-up / strength / metcon); labels, intensity, notes
   └─ [Group?]                коробка схем: ordered contiguous members + opaque coach-owned label
      └─ Schema               примитив: repetition (once/count/ladder/timeCap/cadence/interval) + rest
         └─ [row-grouping?]   коробка на строках: contiguous члены 2+, opaque label (D-PLAQUE)
            └─ Row            payload + typed modifiers + human text
```

- No recursion: `Schema.parentSchemaId` dies (D-3).
- A Group never interprets its label; membership is the only relation; grouping is an explicit gesture (DnD / batch checkbox); nothing is derived from child count (D-2). No typed relation kinds (D-4).
- `composition` after this spec = `{ repetition?, rest? }` — the arrangement axis dies whole (ordered = natural order; parallel → Group; superset → row-grouping; `interleaveOrder` → a Group display setting).

## 2. The channels rule (D-5)

Every notation → exactly one channel: **С** structure · **Т** typed field (only what a machine actually reads) · **Ч** human text (carried, displayed, never interpreted; concrete carrier per case — library/modifier (D-MODIFIER) / notes (D-PLAQUE: the strip is render, not storage); no blanket chips (D-CHIPS)) · **✕** dropped syntax (brackets, case, word order). Expressibility is mandatory even at cardinality 1; a dedicated type is not. The corpus is the FLOOR, not the ceiling — it is ONE personal plan; group-programming notations (m/f loads, RX/SC) are systematically underrepresented in it.

## 7. What we consciously lose (eyes open)

- **Depth beyond the fixed floors.** Group-in-group is inexpressible. Corpus has zero occurrences; athlete readability is the feature, not the bug. Re-opened only by a real coach need.
- **Machine-readable relation semantics** — until an executor/scoring engine exists. Then a HARDENING pass types the relation kinds that engine reads, designed against it (ADR-0038 principle). BACKLOG-ROUNDS ("5 rounds over the group") lives as label text until that day.
- **Positional auto-application scopes** (standalone load "applies to all preceding") — replaced by explicit per-row data + UI conveniences. The model stops encoding reading-order tricks.
- **Execution & scoring semantics** (D-EXEC-DEFER) — "straight into / no-rest transition", "for time", "score only on rounds 2 & 3", "not for score", "AMRAP at 90%+ effort" are NOTES today. Nothing reads them (no timer/scoring engine — charter non-goal); schema order says "then" but not "without pause". Typed FRESH against the Phase-4 executor (re-introduce-fresh) — likely a sequential-continuous Group mode beside the parallel interleave. NO inert boolean now. The owner flagged the "straight into" gap explicitly; it is the execution layer, deferred whole, not a hole in the primitive.

## 8. Re-expression of the hardest corpus cases

1. **Parallel ladders** (block-005 `12-9-6:` ‖ `6-9-12:`): Group of 2 ladder-schemas (each `repetition.ladder` + movement rows). Label optional — the box is the message.
2. **Rounds over parallel** (block-010, depth-3 today): Group labeled "5 rounds:" of N ladder-schemas. Typed rounds-on-Group deferred (BACKLOG-ROUNDS).
3. **BSS drop-set** (block-008): one schema, `repetition.count = 3 sets`, stages as rows: `5 reps @ DB {count:2, 15kg}` / `5 reps @ DB {count:1, 15kg}` / `5 reps, load bodyweight, text "EXPLODE"` + `media{EXPLODE-url}`. Header stays a field (D-HEADER-KEEP).
4. **`5 strict bar dips OR 10 push ups`** (block-105): two exercise rows in a row-group labeled "OR" (D-PLAQUE).
5. **Asymmetric L/R pairs** (block-073): two plain rows with `side: left` / `side: right` — no special case (confirmed non-edge by the analysis itself).
6. **`12 strict pull-ups [ before BAR DIPS complex ]`** (block-051): exercise row + a row note (D-PLAQUE).
7. **EMOM with MAX slot** (block-080): cadence schema; slots as rows; `MAX DB front squats` = `reps.max` + load.
8. **Split-tier** `[5 KB 24 + 10 DB 15]` (block-119): a row-group of 2 rows with own reps+loads (D-LOAD-FINAL — `split_tier` weight variant dies into structure).
9. **Per-set substitution** (block-020): slot row + per-set rows under a row-grouping (no typed mapping) — RATIFIED.
10. **Wall-clock window** (ex-`repetition.window`, deleted by ADR-0039): a 20-min cap stays the faithful expression (`timeCap`); a literal clock-span, if ever needed, is a note until an engine reads clocks.
