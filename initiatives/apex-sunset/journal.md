  - **Legacy backend** (`tdp/mobile-backend`, Spring Boot 3.5.3, ~3k LoC): 7 tables, ZERO athlete-generated data (users + 4 catalogs + `general_programs`/`individual_programs` free-text days, ~hundreds of rows, ids ~576). No integrations at all (no APNs/email/storage/cron). Prod = self-hosted VPS, Docker Compose + Caddy, Postgres container, NO migration tool (prod schema drifted from `schema.sql` — trust only live introspection). A SECOND live backend serves `/dev-api/*` off a separate schema in the same Postgres. Security holes: exact-path Spring matchers leave `PUT /user`, `DELETE /user/{id}`, `changeTrainingLevel/changeUserPlan` open to ANY authenticated user (IDOR incl. delete-anyone); `GET /user` leaks full PII to any athlete; `changePassword` is `permitAll` (brute-force oracle). CI "tests" run nothing (`skipTests=true`). Last commit 2025-10.
  - **iOS app** (`tdp/mobile-ios`, 3.8k LoC SwiftUI, iOS 18+, live App Store v1.0.9): athlete side = read-only program viewing; NO result logging, NO offline (online-only, nothing cached), NO server push — the monthly payment reminder is a LOCAL `UNCalendarNotificationTrigger` (day 1, 09:00), survives the backend's death untouched. ONE central client; base URL hardcoded `thedisciplineprogram.com` + `/api` (DEBUG `/dev-api`) + `/v1`. 8 of its 15 endpoints are admin authoring the platform already superseded → real compat surface = 9 endpoints. Wire traps catalogued (raw auth header, 200-only, `yyyy-MM-dd`, `PROGRAM_ID` header, `fatalError` on `isRestDay:false`+null program, 403-driven sign-out). Zero tests, manual Xcode releases, single author, bus factor 1.
  - **Platform**: web athlete surface already exceeds the app (timetable, session detail, logging, 1RM, records; Wd-1/Wd-2 shipped, Wd-3 in flight). NO non-browser auth path exists (cookie-only NextAuth) — the shim's bearer wrapper is additive next to the four session wrappers in `api-routes`. ADR-0020 §1 pre-reserved `/api/v1/*` for exactly this consumer. Existing assets to reuse: verified wire contract (`mobile-publish/legacy-contract.md`), tested day projection (`project-day.ts` + parity suite), the docker legacy harness, `MobilePublishedDay` ledger, Individual links' `athleteId ↔ legacyUserId` bridge.
